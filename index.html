Atualmente estou estudando cybersegurança por conta própria, tentando entender os sistemas de dentro pra fora. E quando não estou codando nem quebrando a cabeça com puzzles, provavelmente estou customizando meu Arch Linux até deixar do jeitinho que eu quero.

Casos resolvidos

caso nº 01

Enigma

PHP e MVC

Um desafio de lógica que criei do zero pra testar meus amigos: pistas escondidas, quebra-cabeças e um fio narrativo que só quem presta atenção consegue seguir até o fim. Foi meu playground pra misturar backend em PHP/MVC com design de puzzle — a parte mais difícil não foi o código, foi calibrar o nível de dificuldade pra ser desafiador sem ser injusto.

caso nº 02

American Horror Story

API REST e React

Construí uma API própria reunindo os personagens de American Horror Story: Asylum — nomes, intérpretes, imagens oficiais — e depois um site que consome tudo isso de forma dinâmica e temática. Do dado bruto até a tela final, o projeto inteiro é meu, da API hospedada na Vercel ao frontend.

caso nº 03

Sistema de Delivery

em desenvolvimento

Laravel, PHP, MySQL, Bootstrap e Blade

Sistema completo de delivery em que o cliente monta o pedido e paga direto pelo Pix ou cartão de crédito, via integração com a API do Mercado Pago. Do outro lado, o administrador da lanchonete gerencia o estoque de produtos e acompanha os pedidos recebidos em tempo real.

caso nº 04

SaaS de automação

em desenvolvimento

Laravel, PHP, MySQL, Bootstrap e Blade

Um SaaS que vai reunir, num único painel de controle, todos os bots que já desenvolvi ao longo do tempo pra automatizar processos — cada um configurável e monitorável num só lugar, em vez de espalhado em scripts soltos. O objetivo é trazer mais eficiência e controle sobre os processos automatizados, deixando os bots que já desenvolvi e os que ainda estou desenvolvendo muito mais apresentáveis.
